# Glossary

Terms specific to SmartKey or to UNILAG operations.

| Term                    | Meaning                                                                                                                                                                                                                                                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Senate Building**     | The administrative building at UNILAG that houses departmental offices. Two zones: New Senate and Old Senate.                                                                                                                                                                                                                         |
| **CSO**                 | Chief Security Officer. Senior administrator with system-wide oversight.                                                                                                                                                                                                                                                              |
| **Dean**                | Faculty member (formerly labelled HOD — Head of Department) responsible for authorising key collectors for their faculty's keys and approving weekend access requests. The system role is `DEAN`. Internal identifiers (`hod_decisions`, `HOD_APPROVED`, `/api/requests/hod-decision`) retain the old name for historical continuity. |
| **Verifier**            | Security personnel on duty at the Senate Building security desk. Two officers per shift, 24/7.                                                                                                                                                                                                                                        |
| **Requester**           | University staff member requesting access to a room key.                                                                                                                                                                                                                                                                              |
| **External requester**  | A non-registered person who submits a weekend-only key request authorised by a Dean or the CSO. Represented by a `guest_requesters` row, not a profile/auth user.                                                                                                                                                                     |
| **Authorisation slot**  | One of three positions per key where the Dean (for faculty keys) or CSO (for Administration keys) can whitelist a staff member. Maximum 3 authorised collectors per key.                                                                                                                                                              |
| **Code**                | The 6-digit numeric verification code generated when a request is approved. Valid 10 minutes. Required at the desk to collect a key.                                                                                                                                                                                                  |
| **Risk tier**           | Low / Medium / High. Computed at request time by the rule-based engine. Visible to verifiers.                                                                                                                                                                                                                                         |
| **Shift handover**      | Process at the start of every 8-hour shift where the incoming officer acknowledges all outstanding keys from the previous shift.                                                                                                                                                                                                      |
| **Outstanding key**     | A key that has been issued but not yet returned.                                                                                                                                                                                                                                                                                      |
| **Overdue key**         | An outstanding key past its return deadline (typically 17:00 EOD).                                                                                                                                                                                                                                                                    |
| **Weekend access**      | A separate request type requiring Dean (or CSO for Administration keys) approval before a code can be generated.                                                                                                                                                                                                                      |
| **Memo**                | The (formerly paper) document by which a Dean authorised a collector or approved weekend access. In SmartKey, replaced by digital approvals signed by reference signature.                                                                                                                                                            |
| **Authoriser**          | Whoever decides a unit's weekend requests and authorisation slots, set by `units.authoriser`: the faculty's Dean (`DEAN`) or the CSO (`CSO`, Administration only).                                                                                                                                                                    |
| **Weekend decision**    | A Dean or the CSO approving or declining a weekend request. One module (`decideWeekend`, `src/lib/requests/decide-weekend.ts`) serves the dashboard and the emailed one-click link.                                                                                                                                                   |
| **Held approval**       | A Dean's approval blocked because the request's letter or stamp failed signature verification. It exists as a `SIGNATURE_MISMATCH` audit entry, not a request status; only the CSO can release it, by approving or declining the request.                                                                                             |
| **Signature reference** | The Dean's onboarded signature image, post-Sharp processing. Used for pixel-level matching of subsequent approvals.                                                                                                                                                                                                                   |
| **Anomaly**             | An event flagged by the system as unusual: out-of-hours activity, signature mismatch, etc. Surfaced on the CSO dashboard.                                                                                                                                                                                                             |
| **Audit log**           | The append-only table of every operationally significant event. The system's evidentiary backbone.                                                                                                                                                                                                                                    |
| **Zone**                | One of two physical areas of the Senate Building: New Senate or Old Senate. Each has its own operational hours and key inventory.                                                                                                                                                                                                     |
